# 우리 동네 메뉴를 세계로: 서비스러닝 설문

## 파일
- `index.html`: 조사자 홈 (조사자·상권 선택 → 사장님 설문 / 관광객 QR)
- `owner.html`: 사장님 설문 (한국어)
- `visitor.html`: 관광객 설문 (English · 日本語 · 简体 · 繁體 · Tiếng Việt · 한국어)
- `config.js`: 설정 (구글 주소, 팀원, 상권)
- `core.js`, `style.css`: 공통 기능·디자인
- `apps-script.gs`: 구글시트에 붙여넣을 코드 (깃헙에는 안 올려도 됨)

## 설치 3단계
1. **구글시트**: 새 시트 만들기 → 확장 프로그램 → Apps Script → `apps-script.gs` 내용 붙여넣기 → 저장
   → 배포 → 새 배포 → 유형 "웹 앱" → 액세스 권한 **"모든 사용자"** → 배포 → 웹 앱 URL 복사
2. **config.js**: `SCRIPT_URL: ''` 따옴표 안에 복사한 URL 붙여넣기
3. **깃헙**: 새 저장소에 파일 업로드 → Settings → Pages → main 브랜치 저장
   → `https://(아이디).github.io/(저장소명)/` 접속

## 현장 사용
- 조사자는 `index.html` 열고 이름·상권 선택
- 사장님: "사장님 설문 시작"
- 관광객: "QR 보여주기" → 관광객 폰으로 스캔 (조사자·상권이 QR에 자동으로 담김)
- 인터넷이 끊겨도 폰에 저장했다가 연결되면 자동 전송
